Understanding Flexbox sizing with the flex property

Скорочення `flex` задає grow, shrink і basis. `flex: 1` розподіляє доступний простір між елементами.

Живий приклад

flex: 1
flex: 2
flex: 1

Основний CSS

                    .item { flex: 1; } .item--wide { flex: 2; }
